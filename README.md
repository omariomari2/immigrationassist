# Immigration Assistant

An attempt to bring immigration information, status tracking, and employer research into one interface.
The project follows three areas: entry, stay, and employment options.

## In this repository

- A React and TypeScript dashboard built with Vite.
- CSV processing scripts for employer and opportunity data.
- Separate chatbot, status, and Global Entry extension components.

## Run the dashboard

```sh
npm ci
npm run dev
```

Open the address printed by Vite. Run `npm run build` to build the dashboard.
These commands start the frontend only. Other components need their own service configuration.

## Scope

This is an exploratory application. Information and generated answers require source checks.
Use synthetic records when testing document and status features. The project does not establish legal eligibility or submit filings.
